# Contributing to DeskTwin

Keep the desk scene primary. New panels should be contextual rather than permanently occupying the workspace.

## Setup

Use Node.js 26 (`.nvmrc`) and run `npm ci`. Start with `npm run dev`; no API key is required for local work. Read `AGENTS.md`, `docs/ARCHITECTURE.md`, and `docs/PRIVACY.md` before changing inference or data handling.

## Before a pull request

```bash
npm run format
npm run check
npx playwright install chromium
npm run test:e2e
npm run test:production
```

Explain what changed, the user flow it enables, and how it was tested. Include desktop and narrow-viewport screenshots for UI changes. Keep credentials, `.env`, personal desk photos, request logs and dependency directories out of commits.

## Non-negotiable evidence rules

A photo is not live telemetry. A user-reported connection is not verified operation. AI proposals must remain proposals until explicit confirmation. New integrations must preserve provenance and record uncertainty instead of inventing capability/status fields.

## Assets

Use original assets or assets with an explicit compatible license and attribution. Keep the source and license with imported assets. Existing scene geometry and pixel textures are generated by repository code. Use Phosphor icons rather than arbitrary copied brand artwork.

## Scope discipline

Prefer small, independently runnable commits. Add tests for graph invariants and failure states, not only happy-path screenshots. Do not change repository visibility, deploy externally, or add automatically billed API loops as part of a routine contribution.
