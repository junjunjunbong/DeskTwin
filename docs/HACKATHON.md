# Hackathon notes

Source: [Participant guide](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/details), accessed 2026-10-27. Check the live guide, official rules, and submission form again before submitting; details can change.

## Submission facts from the guide

- Deadline: 2026-11-04 21:00 Eastern Standard Time, or 2026-11-05 11:00 Korea Standard Time.
- Submit through Cerebral Valley. Repositories must be public and the video link accessible.
- A three-minute demo video must highlight the features, code, and functionality built during the hackathon. Clearly identify new work, including when building on existing code.
- The project must incorporate Meta models; initial screening checks fit and reasonable use of Meta Model API and/or Meta open-weight models.
- The guide lists impact 30%, use of Meta AI tooling 25%, technical depth and execution 20%, and demo 25%.
- The guide lists basic RAG and simple image analyzers among example anti-projects; DeskTwin must demonstrate a useful workflow beyond basic image analysis.

## Setup and delivery checklist

- [ ] Confirm the claimed Meta Model API credit appears in Billing and that billing is configured.
- [ ] Set a spend alert and monitor usage; alerts are not hard limits.
- [ ] Create an API key locally and verify a small request; never commit the key.
- [ ] Decide on the first demo, model, and implementation stack.
- [ ] Implement and verify photo interpretation, user-confirmed topology, and one troubleshooting flow.
- [ ] Prepare a three-minute demo and identify the new work.
- [ ] Review code, data, images, dependencies, and Git history for rights and secrets before making the repository public.
- [ ] Make the repository public and check repository and demo access from a signed-out session.
- [ ] Submit through the platform and verify confirmation before the deadline.
