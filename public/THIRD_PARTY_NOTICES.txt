HEIC / HEIF decoder
-------------------
Package: libheif-js 1.23.5
Author: Kiril Vatev
License declared by package: LGPL-3.0

The browser loads the package's pure-JavaScript libheif build in a local worker
only when native image decoding cannot handle a HEIC / HEIF photo. DeskTwin does
not edit the decoder source. The application worker is built separately from the
main UI; rebuilding with a replacement decoder uses the ordinary npm/Vite build.
